Política de privacidad de ExpiryTracker

Última actualización: septiembre de 2026

ExpiryTracker es una aplicación diseñada para ayudar a los usuarios a gestionar productos y sus fechas de caducidad. Esta política explica qué información utiliza la aplicación y cómo se trata.

1. Información que gestiona la aplicación

ExpiryTracker permite al usuario introducir y gestionar información relacionada con sus productos, como:

  • Nombre del producto.
  • Marca y categoría, cuando estén disponibles.
  • Código de barras, cuando exista.
  • Fecha de caducidad.
  • Cantidad.
  • Ubicación de almacenamiento.
  • Imágenes asociadas a los productos.

2. Almacenamiento local

La información del inventario se almacena localmente en el dispositivo del usuario. ExpiryTracker no requiere crear una cuenta ni iniciar sesión y no almacena el inventario del usuario en servidores propios.

Actualmente, ExpiryTracker no utiliza el inventario local del usuario para publicidad personalizada, analítica o seguimiento.

3. Cámara y fotografías

La aplicación puede solicitar acceso a la cámara para escanear códigos de barras y para permitir al usuario tomar fotografías que quiera asociar a sus productos.

Las fotografías tomadas por el usuario se utilizan para gestionar el inventario y se almacenan localmente en el dispositivo.

4. Galería de imágenes

La aplicación puede solicitar acceso a la galería de imágenes para que el usuario seleccione fotografías que quiera asociar a sus productos.

Las imágenes seleccionadas se utilizan dentro de la aplicación y se almacenan localmente en el dispositivo.

5. Notificaciones

ExpiryTracker puede utilizar notificaciones locales para avisar al usuario sobre productos próximos a caducar.

Estas notificaciones se generan en el propio dispositivo y no requieren enviar el inventario del usuario a un servidor.

6. Consulta de productos mediante código de barras

Cuando el usuario utiliza la función de búsqueda de productos mediante un código de barras, ExpiryTracker puede enviar ese código de barras mediante una conexión HTTPS a Open Food Facts para intentar obtener información pública del producto correspondiente.

Esta consulta se limita a la búsqueda del producto mediante su código de barras. ExpiryTracker no envía el inventario completo del usuario a Open Food Facts.

El tratamiento realizado directamente por Open Food Facts está sujeto a sus propias condiciones y política de privacidad.

7. Datos personales y servicios de terceros

ExpiryTracker no requiere que el usuario proporcione datos como nombre, dirección, contraseña o número de teléfono para utilizar las funciones principales de la aplicación y actualmente no dispone de cuentas de usuario.

La aplicación no utiliza actualmente servicios de publicidad personalizada, seguimiento de usuarios, analítica de uso o servicios externos de generación de informes de errores.

La única comunicación externa prevista actualmente por la aplicación es la consulta a Open Food Facts cuando el usuario utiliza la búsqueda mediante código de barras.

8. Compartición de información

El inventario almacenado localmente no se comparte con terceros desde ExpiryTracker.

Cuando el usuario solicita información de un producto mediante un código de barras, dicho código puede enviarse a Open Food Facts para realizar la consulta correspondiente.

9. Seguridad

La información del inventario permanece en el dispositivo del usuario y queda sujeta a las medidas de seguridad proporcionadas por el sistema operativo y el propio dispositivo.

Las consultas realizadas a servicios externos por ExpiryTracker se realizan mediante conexiones HTTPS para proteger la información durante su transmisión.

10. Eliminación de datos

El usuario puede eliminar los productos y la información asociada desde la propia aplicación.

ExpiryTracker no almacena actualmente el inventario del usuario en servidores propios, por lo que no existe un inventario remoto que deba solicitarse eliminar.

Al desinstalar la aplicación, los datos almacenados localmente por ella pueden eliminarse conforme al funcionamiento del sistema operativo Android.

11. Cambios en esta política

Podemos actualizar esta política de privacidad cuando sea necesario para reflejar cambios en ExpiryTracker, sus funciones o los requisitos legales. La fecha de actualización indicada al principio de esta página se modificará cuando se publique una nueva versión de la política.
