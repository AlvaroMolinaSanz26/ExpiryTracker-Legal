Política de privacidad de ExpiryTracker

Última actualización: 21 de agosto de 2026

ExpiryTracker es una aplicación diseñada para ayudar a los usuarios a gestionar productos y sus fechas de caducidad. Esta política explica qué información utiliza la aplicación y cómo se trata.

1. Información que gestiona la aplicación

ExpiryTracker permite al usuario introducir y gestionar información relacionada con sus productos, como el nombre del producto, código de barras, fecha de caducidad, cantidad, ubicación de almacenamiento e imágenes asociadas.

2. Almacenamiento local

La información del inventario se almacena localmente en el dispositivo del usuario. ExpiryTracker no requiere crear una cuenta ni iniciar sesión y no envía el inventario completo del usuario a nuestros servidores.

3. Cámara y fotografías

La aplicación puede solicitar acceso a la cámara para escanear códigos de barras y permitir al usuario realizar fotografías asociadas a sus productos. Las imágenes tomadas se utilizan dentro de la aplicación para gestionar el inventario.

4. Galería de imágenes

La aplicación puede solicitar acceso a la galería para que el usuario seleccione imágenes que quiera asociar a sus productos.

5. Notificaciones

ExpiryTracker puede utilizar notificaciones locales para avisar al usuario sobre productos próximos a caducar. Estas notificaciones se generan en el propio dispositivo y no requieren enviar el inventario a un servidor.

6. Consulta de productos mediante código de barras

Cuando el usuario utiliza la función de búsqueda de productos mediante un código de barras, la aplicación puede enviar ese código de barras a Open Food Facts mediante una conexión HTTPS para intentar obtener información pública del producto.

Esta consulta implica el tratamiento del código de barras por parte de Open Food Facts. El tratamiento realizado por Open Food Facts está sujeto a sus propias condiciones y política de privacidad.

7. Datos personales

ExpiryTracker no solicita al usuario datos como nombre, dirección, contraseña o número de teléfono para utilizar la aplicación y no dispone de cuentas de usuario.

No vendemos los datos del usuario ni utilizamos el inventario almacenado localmente para publicidad personalizada.

8. Compartición de información

El inventario almacenado localmente no se comparte con terceros desde ExpiryTracker. La única comunicación externa prevista por la aplicación es la consulta a Open Food Facts cuando el usuario utiliza la búsqueda mediante código de barras.

9. Seguridad

La información del inventario permanece en el dispositivo y queda sujeta a las medidas de seguridad del propio sistema operativo y dispositivo del usuario. Las consultas a servicios externos utilizadas por la aplicación se realizan mediante HTTPS.

10. Eliminación de datos

El usuario puede eliminar los productos y la información asociada desde la propia aplicación. Al desinstalar la aplicación, los datos almacenados localmente por ella pueden eliminarse conforme al funcionamiento del sistema operativo Android.

Para solicitar asistencia relacionada con la eliminación de datos, el usuario puede contactar con nosotros en expirytracker.app@gmail.com .

11. Cambios en esta política

Podemos actualizar esta política de privacidad cuando sea necesario para reflejar cambios en ExpiryTracker, sus funciones o los requisitos legales. La fecha de actualización indicada al principio de esta página se modificará cuando se publique una nueva versión de la política.
