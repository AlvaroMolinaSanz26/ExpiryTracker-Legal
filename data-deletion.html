Eliminación de datos de ExpiryTracker

Última actualización: 21 de agosto de 2026

Cómo eliminar tus datos

ExpiryTracker almacena la información del inventario localmente en el dispositivo del usuario y actualmente no requiere crear una cuenta.

Para eliminar los datos de un producto, el usuario puede utilizar las opciones de eliminación disponibles dentro de ExpiryTracker.

Si necesitas solicitar asistencia relacionada con la eliminación de datos, puedes contactar con nosotros mediante:

expirytracker.app@gmail.com

Datos que pueden eliminarse

Los datos del inventario almacenados localmente por ExpiryTracker pueden incluir nombres de productos, códigos de barras, fechas de caducidad, cantidades, ubicaciones e imágenes asociadas.

Estos datos pueden eliminarse desde la propia aplicación. La eliminación de la aplicación del dispositivo también puede eliminar los datos locales asociados a ella, de acuerdo con el funcionamiento del sistema operativo.

Datos de servicios externos

Cuando el usuario utiliza la búsqueda de productos mediante código de barras, ExpiryTracker puede consultar Open Food Facts para obtener información pública sobre el producto.

ExpiryTracker no controla los datos que puedan ser tratados directamente por Open Food Facts. Cualquier solicitud relacionada con los datos tratados por Open Food Facts deberá dirigirse a dicho servicio.

Retención de datos

ExpiryTracker no mantiene actualmente una base de datos de cuentas de usuario ni almacena el inventario del usuario en servidores propios. Por ello, no existe un periodo de retención del inventario en nuestros servidores.
